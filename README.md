# 💰 SmartSpend – Expense Tracker

A responsive personal expense tracker with budget management and spending analytics.

## 🎯 Purpose

SmartSpend is a simple web-based expense tracker designed to help users manage their personal finances. It allows users to record income and expenses, track their current balance, and organize transactions by category.

## ✨ Features

- 💰 Track current balance
- 📈 Track income
- 📉 Track expenses
- ➕ Add transactions
- 🏷️ Categorize transactions
- 💾 Store data using browser Local Storage
- 📱 Mobile-friendly responsive design
- ⚡ Works directly in the browser
